# 🎓 ระบบติดตามความก้าวหน้าโปรเจกต์นักศึกษา (Student Project Progress Tracker)

แอปพลิเคชันสำหรับอาจารย์และผู้ดูแลโครงการเพื่อบันทึก ติดตาม และประเมินความก้าวหน้าโครงงานนักศึกษาอย่างเป็นระบบ

---

## 🚀 วิธีการเปิดใช้งาน
1. ไปที่โฟลเดอร์ `ProjectTracker`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (เช่น Google Chrome, Microsoft Edge, Firefox, Safari) ได้ทันที
3. ไม่ต้องติดตั้งโปรแกรมหรือรัน Server ใดๆ เพิ่มเติม

---

## ✨ คุณสมบัติเด่นของระบบ

1. **บันทึกข้อมูลนักศึกษา:**
   - รหัสนักศึกษา, ชื่อ - นามสกุล, ชื่อโครงงาน/โปรเจกต์, อาจารย์ที่ปรึกษา, สาขาวิชา
2. **การติดตามความก้าวหน้า 5 ครั้ง (Milestones 1 - 5):**
   - **ครั้งที่ 1:** เสนอหัวข้อและขอบเขตโครงงาน
   - **ครั้งที่ 2:** การศึกษาทฤษฎีและออกแบบระบบ
   - **ครั้งที่ 3:** ความก้าวหน้าการพัฒนาระบบ (50%)
   - **ครั้งที่ 4:** การทดสอบระบบและผลการดำเนินงาน
   - **ครั้งที่ 5:** รูปเล่มรายงานและเตรียมสอบจบ
3. **ฟังก์ชันในแต่ละครั้งของการติดตาม:**
   - กำหนดสถานะ: `ยังไม่ส่ง` / `รอตรวจ` / `ต้องแก้ไข` / `ผ่านเรียบร้อย`
   - ใส่วันที่ตรวจ / วันที่ส่งงาน
   - ใส่คะแนนประเมิน (0-100)
   - ใส่ลิงก์ส่งงาน / ไฟล์แนบ (Google Drive, Github, URL)
   - บันทึกข้อเสนอแนะและสิ่งที่ต้องแก้ไขจากอาจารย์
4. **Dashboard & การแสดงผล:**
   - สรุปสถิตินักศึกษาทั้งหมด, ผ่านครบ 100%, กำลังดำเนินการ, มีงานต้องแก้ไข
   - คำนวณร้อยละความก้าวหน้ารวมอัตโนมัติ (0% - 100%)
   - สลับมุมมองได้ทั้งแบบ **การ์ด (Card View)** และแบบ **ตาราง (Table View)**
   - ค้นหาทันทีตามรหัส, ชื่อ-สกุล หรือชื่อโปรเจกต์
   - กรองตามสถานะการส่งงาน
5. **การจัดเก็บและการส่งออกข้อมูล:**
   - บันทึกข้อมูลอัตโนมัติลงใน **LocalStorage** ในเครื่อง ปิดเบราว์เซอร์แล้วเปิดใหม่ข้อมูลยังคงอยู่
   - ปุ่ม **Export Excel (.xlsx)** ส่งออกข้อมูลรายงานความก้าวหน้าครบทุกคอลัมน์
   - ปุ่ม **พิมพ์รายงาน (Print / PDF)** รองรับการสั่งพิมพ์หน้ากระดาษอย่างสวยงาม
